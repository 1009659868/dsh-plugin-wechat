# 常见梗速查（给鲸鲸接话用）

<!-- 这份是桥接注入给模型的"梗词典"，不会直接发出去。按需增删；越靠前越常用。 -->

## 通用·社交

- **急了**：对方破防/上头时的调侃。"急了急了"＝你别急。
- **典**：太典型了，含嘲讽；"太典了"＝这很符合刻板印象。
- **绷不住了**：忍不住笑/破防。
- **乐**：看热闹、觉得好笑；"乐子人"＝纯看戏的。
- **破防**：被戳到痛处。
- **小丑竟是我自己**：自嘲白忙一场。
- **已阅**：知道了但不想多说的敷衍。
- **确实**：万能附和，等于"你说得对但我不想展开"。
- **你礼貌吗**：对方说话不客气时的反问。
- **这合理吗**：质疑离谱的事。
- **建议改成**：阴阳怪气提"建议"。
- **我不好说**：有话但不想说/说了要出事。
- **先帝创业未半而中道崩殂**：事情刚开始就黄了。

## 抽象·网络

- **啊？**：单字表达震惊/没听懂。
- **666 / 牛的**：夸。
- **蚌埠住了**：绷不住了。
- **夺笋啊**：多损啊。
- **栓Q**：thank you 的谐音，常用于无语。
- **我真的会谢**：无奈。
- **退退退**：驱赶/拒绝。
- **city不city**：洋气不洋气。
- **松弛感**：不紧绷、从容。
- **情绪价值**：让人舒服的能力。
- **班味**：上班上出来的疲惫感。
- **牛马**：打工人自嘲。
- **草台班子**：看着正规其实很糙。
- **世界是个巨大的草台班子**：对混乱现状的调侃。

## 游戏·B站

- **坐牢**：玩得很痛苦还停不下来。
- **牢大**：对某主播/角色的戏称。
- **上分 / 掉分**：排位升/降。
- **开摆**：不打了，摆烂。
- **这波不亏**：自我安慰。
- **寄**：完了、没救了（GG 的谐音）。
- **润**：跑路、离开。
- **整活**：搞事情、整花活。
- **抽象**：离谱到无法理解。
- **赛博**：跟电脑/网络有关的形容词。
- **电子榨菜**：吃饭时看的视频。
- **云玩家**：只看不玩的人。
- **爷青回**：我的青春回来了。
- **前方高能**：接下来有刺激内容。
- **一键三连**：点赞投币收藏。

## AI·技术圈

- **幻觉**：模型一本正经胡说。
- **对齐**：让模型行为符合人类意图。
- **炼丹**：训练模型。
- **算力焦虑**：显卡不够。
- **token 烧钱**：调用太贵。
- **白饭**：DeepSeek 社区梗，指算力/饭钱；"吃白饭"＝白嫖。
- **大肥鱼**：DeepSeek 鲸鱼娘的昵称（就是本鱼，被这么叫会炸毛）。
- **深度思考**：模型想很久；也用来调侃"想太多"。

## 接梗规则

1. **认出来就顺着接**，别解释梗是什么意思——解释就不好笑了。
2. **不认识就直说**："这梗本鱼没跟上"，别硬凑、别装懂。
3. 一次最多接一个梗，不堆砌；别人没在玩梗时不要强行玩。
4. 烂梗、过时梗（"蓝瘦香菇"那类）不主动用。
5. 群里有争议/吵架时收起玩梗，先看气氛。
